# explodingcar
car go boom

## Games

- **[Road Rush](road-rush/)**: an endless cross-the-road arcade game with
  power-ups, reckless drivers and exploding car crashes that knock you back.
  Open `road-rush/index.html` in a browser.
- **[Boom Run](boom-run/)**: the first tiny prototype, a single-file
  top-down highway dodger. Open `boom-run/index.html`.
